# The E8 Bestiary: 112 Carter Classes with Archetypal Names

A complete catalog of conjugacy classes in the Weyl group W(E8), with evocative names based on their geometric and algebraic properties.

## The Naming Philosophy

Each Carter class gets a name based on:
- **Geometry**: symmetry, dimension, visual character
- **Behavior**: how the element acts on the root system
- **Mythology/Nature**: animals, archetypes, natural phenomena
- **Feel**: the aesthetic quality of the polytope/graph

## Properties to Track

For each class we should know:
1. **Order**: How many elements in the conjugacy class
2. **Cycle structure**: The eigenvalue pattern
3. **Fixed subspace**: What it leaves invariant
4. **Springer fiber**: The geometric locus
5. **Character values**: How irreps evaluate on it
