## How the catalogue picks images

- `src/make_catalogue.py` → `catalogue.tex` / `catalogue.pdf` (repo root).
- `IMAGE_OVERRIDES` dict (~line 519) maps a page stem to a repo-root-relative
  image path; overridden pages skip the `individual_graphs/` render.
- `EXCLUDED` set: pages deliberately dropped — currently
  `zhou-quotient-spectral`, `zhou-z2-quotient` (Robin, 2026-06-10).
- Each PDF page's footer shows its source path.

### Style exemplars (provenance)

- `dmt.jpeg` = the triality hexagon, drawn by `surfaces/draw_triality_hexagon.py` (see table above); on disk as `individual_graphs/dmt.{pdf,jpg}`.
- `langer-colour.jpeg` = the Langer 63-vertex drawing from `clayworth/draw_langer.py` (builds in `/tmp/langer_full.*`); canonical on-disk copy `lean/named_graphs/langer-63v.jpg`. No file with the name `langer-colour.jpeg` exists on disk.

## The dmt style

- Canonical generator: `clayworth/generate_named_graphs.py` — registry
  `NAMED_GRAPHS` (per-graph foster id, girth, max_deg, optional
  `"layout": "cyclic"`). Run: `python3 clayworth/generate_named_graphs.py <gap_name>`.
- `src/draw_graph.py --style dmt` reimplements the same TikZ but **do not use
  it for catalogue images** — Robin: "You obviously didn't use the dmt-generator."
- Graphs that degenerate to a vertical line under auto layout (size-2 orbits):
  k4, k33, cr19, f26a, pg23 → `"layout": "cyclic"` in the registry.
